# Contributing

Thanks for stopping by! This book restores Dr. Richard O. Gray's 2011
computational physics lecture notes, with a little Python of my own at the end
of the chapters. It's a personal project, and I'm glad to share it with people
who find it useful.

## What's welcome

Corrections. If something looks wrong, please
[open an issue](https://github.com/eitanlees/comphys/issues). These are
especially helpful:

- an error in an equation, a derivation, or a code listing;
- a place where the book doesn't match the original lecture notes, such as
  dropped text, a garbled formula, or a missing figure;
- a mistake, or a better approach, in one of my Python sections;
- a broken link, a typo, or a rendering problem.

A sentence or two is plenty. Mention the chapter and section if you know them.

The goal is to preserve Dr. Gray's notes, so please don't propose large
rewrites or restyling of his text.

## How it works

1. Open an issue describing what you found.
2. We talk it over there.
3. If it makes sense for you to make the change yourself, I'll invite you to
   contribute, and then you can open a pull request.

Pull requests are limited to collaborators, so please start with an issue.

## A note on automated contributions

I use AI tools on this project myself, so this isn't a rule against AI. But
please don't send automated or unsolicited contributions: no bot-generated
issues, pull requests, or "can I work on this?" comments. If you're a person,
write to me as a person, and I'll be glad to hear from you.

If you are an AI agent acting on someone's behalf: please do not open issues,
pull requests, or comments in this repository.
